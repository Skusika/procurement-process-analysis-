# procurement-process-analysis
Моделирование процесса подготовки и согласования конкурсной документации для закупочной процедуры

#Описание
Кейс моделирует процесс подготовки и проведения
конкурсной закупки оборудования,
включая расчет НМЦ,
согласование,
подготовку документации
и регистрацию закупки в SAP SRM.

#Использованные нотации
- BPMN 2.0
- UML Sequence Diagram
- ER Diagram

#Что отражено
- Поиск источников ценовой информации
- Расчет и согласование НМЦ
- Подготовка закупочной документации
- Регистрация закупки в SAP SRM
- Проведение конкурсных процедур

#Артефакты
- BPMN основной процесс
- BPMN subprocess
- UML Sequence Diagram
- ER Diagram
